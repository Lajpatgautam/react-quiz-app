# 🧠 React Quiz App

An interactive and timer-based quiz application built with React, designed to test users' knowledge through dynamic questions and real-time score calculation.

🌟 This project demonstrates my practical understanding of React fundamentals, component-based architecture, and state management.

---

## 🔗 Live Demo  
👉  https://react-quiz-app-lajpat.netlify.app/
*(Deployed on Netlify)*

---

## ✨ Features

- ⏱️ **30-second timer** for each quiz session  
- 📊 **Automatic score calculation**  
- 🔄 **Dynamic question rendering**  
- 🧠 **User-friendly quiz flow**  
- 📱 **Fully responsive design** (Mobile + Desktop)  
- ⚡ Fast and smooth UI experience  

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **Netlify** (for deployment)
